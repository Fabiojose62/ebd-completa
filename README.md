# 📖 EBD Completa - Escola Bíblica Dominical

Aplicativo completo e profissional para gerenciar Escola Bíblica Dominical com todos os recursos necessários.

## ✨ Funcionalidades

### 📚 Lições
- Cadastro de lições bíblicas
- Referências bíblicas
- Descrição detalhada
- Datas de aulas

### 📅 Trimestres
- Organizar lições por trimestre
- Definir tema do trimestre
- Data de início e fim
- Gerenciar períodos

### 📖 Versículos
- Cadastrar versículos para memorizar
- Categorizar (Amor, Fé, Esperança, etc.)
- Facilita revisão de conteúdo

### 📝 Perguntas e Revisões
- Criar perguntas sobre lições
- Adicionar respostas
- Associar a lições específicas
- Ferramenta de revisão

### 📁 Arquivos
- Adicionar PDFs, imagens, vídeos
- Organizar materiais de estudo
- Links para recursos online

### 📢 Avisos
- Comunicados urgentes
- Níveis de urgência (Alta, Média, Baixa)
- Notificações para a comunidade

## 🚀 Como Acessar

### Online
👉 **https://fabiojose62.github.io/ebd-completa**

### Localmente
1. Clone ou baixe o repositório
2. Abra `index.html` no navegador
3. Tudo funciona offline!

## 💾 Armazenamento

- Dados salvos **localmente no navegador**
- Não requer internet após primeiro acesso
- Funciona como **Progressive Web App (PWA)**
- Pode ser instalado como app no celular

## 📱 Instalar como App

### Android (Chrome)
1. Acesse o site
2. Menu (⋮) → "Instalar aplicativo"
3. Clique em "Instalar"

### iPhone (Safari)
1. Acesse o site
2. Compartilhar (↑) → "Adicionar à Tela de Início"
3. Clique em "Adicionar"

## 🛠️ Tecnologias

- **HTML5** - Estrutura
- **CSS3** - Estilo responsivo
- **JavaScript** - Lógica do aplicativo
- **LocalStorage** - Armazenamento local
- **Service Worker** - Suporte offline
- **PWA** - Instalável como app

## 📊 Estrutura

```
ebd-completa/
├── index.html      # Interface principal
├── style.css       # Estilos
├── script.js       # Lógica
├── manifest.json   # Configuração PWA
├── sw.js          # Service Worker
└── README.md      # Documentação
```
